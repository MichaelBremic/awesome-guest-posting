# Contributing

Thanks for thinking about adding to this list. A few rules before you open a pull request.

## What belongs here

An entry should fit at least one of these categories:

1. A marketplace where guest post placements or sponsored posts are transacted.
2. A software tool used for outreach, prospecting, backlink analysis, or pitch management.
3. A platform connecting sources to journalists (HARO-style services).
4. A high-quality guide, tutorial, blog, newsletter, or book about guest posting or editorial link building.
5. An agency whose core service is link building or guest post placements.
6. A community (forum, subreddit, Slack, Discord) focused on link building or SEO practice.
7. A free tool, calculator, or utility useful to anyone running guest post campaigns.

## Quality bar

- The entry must be actively maintained. If the site, tool, or blog has not published or updated in over a year, it does not belong here.
- The link must work and resolve to the correct resource.
- For tools and marketplaces, a public sign-up or pricing page must exist.
- Books must be in print or available in a digital edition.

## Format

Each entry follows this format:

```
- [Name](https://example.com) - Short description ending with a period.
```

Descriptions should be one sentence, factual, and under 140 characters. Do not use superlatives like "best," "leading," or "number one."

## Ordering

Entries are alphabetical within each section. Case is ignored for sorting. Prefixes like "The" are ignored.

## Disclosures

If you or your employer owns, operates, or is financially connected to the entry you are submitting, say so in the pull request description. Undisclosed conflicts will result in the entry being removed once discovered.

## What gets rejected

- Pay-to-list requests.
- AI-generated descriptions that read as generic. Write the description yourself.
- Entries that duplicate an existing one.
- Listings for services operating on private blog networks (PBNs), click farms, or explicit link-buying schemes that violate search engine guidelines.
- Personal blogs with no link building or guest posting focus.

## How to submit

1. Fork the repository.
2. Edit `README.md` and add your entry in the correct section, in alphabetical order.
3. Run a quick sanity check that your entry follows the format and your link resolves.
4. Open a pull request with a short title and a description that includes the entry's category and any disclosure required above.

If you are unsure whether something fits, open an issue first and ask.
